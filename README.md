# Agent ETD

**Agent Efficient Trajectory Distillation** — 面向 Agent 的高效轨迹蒸馏研究。

目标是在保持任务正确率的同时，降低推理 token 消耗与工具调用成本。

## 核心思路

1. 对每个 query 采样多条解题轨迹，验证正确性并筛选高效轨迹。
2. 若没有合格轨迹，调用更强的模型生成解题 hint，引导重新生成与筛选。
3. 使用筛选后的完整轨迹训练学生模型，使其在无 hint 条件下也能高效完成任务。

## 评估

关注任务成功率、推理 token 数、工具调用次数及数据生成成本。
